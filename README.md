# EventHub

> 🚧 **Work in Progress**
>
> EventHub is currently under active development. Features, API routes, and project structure may change.

EventHub is a full-stack application for organizing events, inviting participants, coordinating dates, managing tasks, and communicating within events.

## Tech Stack

### Backend
- Java 26
- Spring Boot 4.1
- Spring Security
- OAuth2 Resource Server
- JWT authentication
- Spring Data JPA
- Hibernate
- PostgreSQL
- Flyway
- Maven

### Frontend
- Next.js
- React
- TypeScript
- Zustand
- TanStack Form
- Zod

### Infrastructure
- Docker
- Docker Compose
- Adminer

## Features

### Implemented
- User registration
- User login
- Access JWT authentication
- Refresh token authentication using HttpOnly cookies
- Protected API routes
- Public user profiles
- Current user profile
- Profile editing
- Password changing
- Account deletion

### Planned / In Progress
- Event creation and management
- Event invitations
- Event participants
- Date voting
- Event tasks
- Comments
